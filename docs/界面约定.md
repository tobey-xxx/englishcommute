# EnglishCommute 界面约定

> 这是**项目文档**，不是工作记忆。工作记忆（`.workbuddy/memory/MEMORY.md`）有注入体积上限，
> 里面的界面部分只留指针与最关键的几条陷阱；完整清单在本文。
>
> 通用做法（下拉关闭三段结构、长列表浏览、明暗双主题与无障碍）已沉淀为 skill：
> `android-compose-gesture-dismiss` / `android-compose-list-ux` / `android-compose-dual-theme`。
> 本文只写**项目专属的 token、常量与那些「不报错但会错」的陷阱**。

## 动效统一入口 `ui/theme/Motion.kt`

- 时长 **120 / 220 / 320** + 三条曲线；**界面里不许散落 `tween(...)`**
  （烟花那个线性循环时钟是唯一豁免），构建断言会扫。主题过渡时长也收进 `Motion.themeMix()`。
- ★ **两条缓动曲线曾是「实现与注释相反」，只有算起手斜率才发现**：
  现为 `EasingStandard=(0.32,0.72,0,1)` 斜率 **2.25**、
  `EasingExit=(0.2,0.85,0.3,1)` 斜率 **4.25**、`EasingEnter` 14 不动。
  锁在 `tools/verify-motion-128.py`（从源码解析控制点算斜率）。
  **教训：曲线对不对看不出，只能算。**
- **死代码纪律**：定义了没人调的函数比没有更糟 —— 它让人以为「这里已经处理过了」
  （`transcribeManually` 就这样躺了一个版本）。加工具 API 前先数调用点。

## 卡片与材质

- 卡片 token：`Card` / `CardEdge` / `CardChip`（+ `Radius.card/cover/pill`）。
  ⚠️ `CardChip` 必须**半透明**，不能沿用页面级 `BgRaised`（深色下差 3/255 等于没底色）。
- **按下反馈只有一条 API：`Modifier.pressFeedback`**；全工程**不许裸 `Modifier.clickable`**
  （之前 59 个可点元素按下去什么都不发生）。缩放 `PressScale.Control=0.96` / `.Row=0.985`；
  **文字链接用 `pressedAlpha` 变淡**（12.5sp 缩 4% 只有半个像素）。
- ⚠️ **Compose 没有 `backdrop-filter` 的等价物**（`Modifier.blur` 模糊的是自己不是身后）→
  「材质」只能做到「一块底 + 一条上边缘 / 边界的渐隐带」。**别再以为能做真背景模糊。**
- **播放页材质化（1.2.10）**：字幕层铺满整屏、从顶栏与控制区**下面穿过**；两块材质高度
  `onSizeChanged` **量**出来（标题可能两行、翻译状态行可能不出现），初值给估算值兜底；
  边界用 16dp `ScrollEdgeFade` 替代 1px `Hairline`；控制区底色 `BgRaised`→`Bg`；
  **「当前句停上 1/3」要按可见区算**（否则它落进顶栏底下）。
- **三页卡内边距刻意不同**：素材库 **13** / 打卡 **16** / 设置 **14**
  （是 1.2.0 特意做的节奏，别顺手统一）。设置页改一处 `Block()` 即可；打卡页抽 `CheckInCard`；
  **刊头不卡片化**。
- 明暗切换用**色板插值**（`mixPalettes` + `Motion.themeMix()`），**不用 `Crossfade`**
  （那个同时持有两棵树 → `LaunchedEffect` 跑两遍、列表状态两份）。
- **两个无障碍信号各自有做法**：`areAnimatorsEnabled()` → 去位移 / 缩放、**保留**淡入淡出；
  `isHighContrastTextEnabled()` → 只提 `inkFaint` / `hairline` / `cardEdge` 三层配色。
  ⚠️ **必须走 Compose 状态**（`mutableStateOf` + `LifecycleEventEffect(ON_START)` 刷新）；
  写成 `@Volatile var` 在 `onStart` 改值 —— 能编译、能改到值，但**没有读者、界面不重组**。
- ⚠️ 高对比是 `isHighContrastTextEnabled`，不是直觉更顺的 `isHighTextContrastEnabled`
  （编译不过）。`UiModeManager.getContrast()` 返回 **float 且无档位常量**，不适合做判据。

## 覆盖层 / 形变 / 列表

- **判定顺序是硬契约**：`velocity > fling` → 关，`velocity < -fling` → 回弹，
  **都判完了才看位移**。顺序反了只是「甩一下关不掉」，**不报错**。锁 `verify-motion-129.py`。
- ⚠️⚠️ **覆盖层内部 `remember` 的状态会跨「关闭 → 再打开」存活**（1.2.10 真机 bug）：
  退出动画 220ms 内再次打开会**取消退出、保留实例** → 按 `episodeId` 作 key 的
  `LaunchedEffect` **不重跑** → 上一轮留下的 `offsetY`（1000dp）还在，页面停在屏幕外。
  **判据在日志里**：只有「迷你条点开」、紧跟的「进入播放页 · 」消失 = 实例被保留了。
  正解：自增 `openNonce` 作复位 key，**每条打开路径都要自增**。
- ⚠️ **位移一律走 `graphicsLayer`**，不要 `offset { }`：后者是**布局层**位移，
  每帧都会让整棵子树重新测量与布局。
- ⚠️ **别让两套位移叠在同一屏**：整页 `slideInVertically` + 共享元素 bounds 补间
  = 又慢又「斜着飞」。形变开启时进页只淡入淡出。
- ⚠️ 形变：开关 `ui/Morph.kt` 的 `SHARED_MORPH` + 键 `MORPH_COVER_KEY`（**只定义一次**，
  两端引用；两端键不一致 ＝ 形变不发生且不报错）。迷你条常驻、**拿不到 `AnimatedVisibilityScope`**
  → 那端用 `sharedElementWithCallerManagedVisibility`，
  ⚠️ **它的 `visible` 默认 `true`，漏接线编译期完全不提醒**（后果是两端同时「在场」）。
  **回退要「真的不包」**（连 `SharedTransitionLayout` 都不建，否则 `LookaheadScope`
  的额外测量还在）。**只共享封面**，不做整块材质的 `sharedBounds`。
- **`Root()` 顶层不许读每 250ms 更新的播放状态**（pager 预排会让三个页签全 composed
  → 每秒重组 4 次）。**推论**：读「每帧都在变」的状态（`layoutInfo`、滚动位置）
  必须和画图待在**同一个 Composable** 里（外层只传 `listState` 对象、不读它的字段）。
- **`pointerInput` 的 block 只在 key 变化时重启** → 里头直读每帧变化的量会读到**陈旧值**
  （表现：滑块与手指对不上，不报错）→ 用 `rememberUpdatedState`。
