# 第三方资源与许可

本仓库的**代码**是 MIT（见根目录 `LICENSE`）。但仓库里还带着三类**外部来源的数据/代码**，
它们各自有自己的许可与署名要求 —— 部署或分发前请逐一确认。

| 资源 | 位置 | 来源与许可（请自行核实） |
| --- | --- | --- |
| 词库（词形 / 音标 / 释义） | `app/src/main/assets/vocab/vocab.base`、`vocab.forms` | 数据格式与字段风格与 **ECDICT** 一致（GitHub: `skywind3000/ECDICT`，MIT）。若确实来自它，**必须保留其版权与许可声明** |
| 例句与中文译文 | `app/src/main/assets/vocab/examples.base` | 疑似来自公开例句集（如 Tatoeba，CC-BY 2.0 FR）或词典自带例句。**请确认后再公开** |
| FSRS 参考实现 | `tools/fsrs-reference/`（`fsrs/` 包） | **py-fsrs**（MIT）。`app/.../word/Fsrs.kt` 是它的 Kotlin 移植，算法对照见 `FsrsTest` |
| 播客音频 / 封面 / 字幕原文 | 运行时下载，**不在仓库里** | 版权归各内容源（NPR / BBC / CBC / WSJ / Al Jazeera / TED 等）。本项目的 `server/` 只是抓取与转写的工具，**不包含也不分发任何节目内容** |

## 给部署者的两点提醒

1. **个人学习 vs 公开发布**：把 `server/` 跑起来给自己听没问题；**对外提供服务**属于再分发内容，
   需要逐家确认条款（多数播客允许个人收听，不允许转售或批量再分发）。
2. **转写文本**（`subs/*.srt`）是对音频的衍生作品，同样受原内容版权约束。
   本仓库不包含任何转写结果；`www/`、`data/`、`logs/` 都在 `.gitignore` 里。

> 如果你要把它作为「公开服务」上线，最稳的做法是：只保留**公共领域 / CC 授权**的源，
> 并在 `server/bin/feeds.txt` 里注明每一源的许可。
